System Architecture

Virtual Physics Laboratory Engine

Engineered with zero external libraries using vanilla ES6+ JavaScript and HTML5 Canvas 2D to simulate classical mechanics and wave superposition at a locked 60 FPS timestep.

01 // FIXED-TIMESTEP SOLVER

Clamped 16.67 ms integration loop using RK4 and semi-implicit Euler methods to prevent numerical energy drift.

02 // RETINA CANVAS PIPELINE

Device-pixel-ratio aware rendering pass separating physics state updates from vector grid and trajectory drawing.

03 // PARAMETRIC CONTROLS

Live sliders adjust frequency, damping ratio, launch velocity, and gravitational acceleration in real time.

04 // ZERO DEPENDENCIES

Self-contained browser execution ideal for instant classroom demonstrations and ECE wave/RLC analogies.
